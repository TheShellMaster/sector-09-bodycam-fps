# Code de Conduite

Ce projet adhère au **Contributor Covenant**. En participant à **SECTOR 09 // BODYCAM** (issues, discussions, pull requests), vous vous engagez à :

- Faire preuve de respect, de bienveillance et de constructivité dans les retours de code.
- Accueillir les débutants comme les développeurs Godot expérimentés.
- Ne publier aucun contenu malveillant, offensant ou protégé par des droits d'auteur sans autorisation (notamment pour les modèles 3D, textures et sons).

Tout comportement inapproprié peut être signalé aux mainteneurs du dépôt.
